# Lifecycle: implementing

The decision is settled (see `lifecycle: decided`) and code is
actively being written. The work is in flight but not yet considered
finished.

## When to use

- A roadmap entry whose feature is partially shipped
- An ADR whose pattern is being applied across the codebase

## Difference from `stable`

Implementing = "code is in flight"

Stable = "shipped and used in production"
