# Lifecycle: planning

The work the doc describes is in active exploration. Options are
being considered; no path has been committed to.

## When to use

- A research doc with an open question
- An ADR draft that hasn't reached a conclusion

## Difference from `decided`

Planning = "we're still figuring out the approach"

Decided = "we know what we're doing; nothing built yet"
