# Migration 0001 — Initial ontology

Bootstrap migration generated by `doc-linter init`. Introduces the
four classification axes and a starter vocabulary.

## What's in v1

| Axis | Vocabulary type | Starter values |
|---|---|---|
| `role`      | closed (+ meta) | doc, index, adr |
| `kind`      | closed          | tutorial, how-to, reference, explanation |
| `lifecycle` | closed          | planning, decided, implementing, stable, superseded |
| `covers`    | open            | example (single placeholder entity) |

Plus the four meta-roles used by ontology docs themselves:
`ontology-axis`, `ontology-value`, `ontology-entity`,
`ontology-migration`. Those are hardcoded in the doc-linter so the
ontology can describe itself.

## Next steps for this repo

1. Edit [[entity-example]] or replace it with one entity per real
   domain concept in [`../entities/`](../entities/).
2. Add real `role: doc` content to your repo, declaring `covers:`
   for the entities each doc touches.
3. (Optional) flip `vale_enabled = true` in `.doc-lint.toml` once
   you've installed Vale + scaled the entity vocabulary out.

## Adding new closed-vocab values

For new role / kind / lifecycle values:

1. Bump `ontology_version` in [[ontology-index]].
2. Add a value doc under `values/<axis>/`.
3. Write a follow-up migration here describing the change and how
   existing docs may need to update.
